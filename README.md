# Amazon Sales Analysis Dashboard

## Project Overview
Built an interactive Amazon Sales Analysis Dashboard using SQL and Power BI.

The dashboard analyzes:
- Revenue performance
- Customer ratings
- Discount impact
- Category-wise analysis
- Product insights

---

## Tools Used
- SQL (MySQL)
- Power BI
- DAX
- Power Query

---

## Dashboard Features
- KPI Cards
- Revenue Analysis
- Ratings Distribution
- Scatter Plot Analysis
- Interactive Filters
- Business Insights

## Key Insights
- Electronics generated highest revenue.
- Most products maintained ratings above 4.
- High discounts showed mixed customer response.
- Revenue growth observed across categories.
